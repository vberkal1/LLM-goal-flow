# Workflow разработки

## Общий процесс
1. выбрать milestone
2. разбить на задачи
3. реализовать
4. проверить
5. перейти дальше

---

## Правила
- не перепрыгивать milestone
- не усложнять MVP
- сначала работает → потом красиво

---

## Структура фичи
- model (zustand)
- ui (components)
- lib (utils)

---

## Проверки

### Перед коммитом
- typecheck
- eslint
- билд

### Definition of Done
- работает без ошибок
- покрывает основной сценарий
- нет лишнего UI
- соответствует минимализму

---

## Работа с состоянием
- один store
- slices:
  - goalSlice
  - taskSlice
  - uiSlice

---

## Работа с localStorage
- загрузка при старте
- сохранение при изменении
- debounce 300ms

---

## Таймер
- один активный
- хранится в store
- синхронизация с localStorage

---

## UI
- только MUI
- кастомизация через theme
- без inline стилей

---

## Ошибки
- не блокируют UI
- fallback значения

---

## Build validation
- npm run build
- нет TS ошибок
- приложение стартует
